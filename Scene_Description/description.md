# 场景描述：雨林
## 场景概述
雨后的林间，雨水刚刚停歇，空气湿润安静。林间没有激烈的声响，整体氛围舒缓、静谧，充满自然的生机。
场景以持续的环境底音作为基础，搭配间歇性随机出现的自然音效，营造沉浸式的野外听觉空间。

## 听觉设计思路
整体采用**2D背景基底 + 3D空间音效**的组合方案：
环境音铺满整个场景，不受距离影响，让玩家始终处在森林的氛围之中；鸟鸣、虫鸣、水滴声作为局部声源，具备空间距离衰减，声源远近变化时音量随之改变，增强空间真实感。
音效采用随机容器，每次触发播放不同采样，避免重复感，还原自然界声音随机、不规律的特点。

## 声音分层
1. **底层｜2D环境基底音（Forest_Ambience_Base）**
持续循环的雨后森林环境音，包含湿润泥土、微风、远处微弱林响，作为场景底色，全程不间断播放，无距离衰减。

2. **中层｜3D随机音效组**
- 鸟鸣（RC_BirdCall）：林间不同位置偶尔响起鸟叫，3D声源，随距离衰减；一共3组不同鸟鸣采样，触发时随机选取一条。
- 虫鸣（RC_InsectCall）：潮湿草木间断断续续的虫鸣，3D声源，随距离衰减；一共3组虫鸣采样，随机播放。

## 交互听觉表现
- 背景音一旦触发就持续循环，不会自动停止；
- 鸟鸣、虫鸣为单次触发音效，播放完毕自动结束；
- 3D音效支持空间距离变化：声源靠近听者，音量变大；声源远离听者，音量逐步衰减变小；
- 同一事件多次触发，会随机选出容器内不同音频，模拟自然里声音随机出现的效果。

## 氛围目标
安静、清新、松弛，传递雨后森林湿润、宁静又富有生机的感受，适合作为休闲向游戏野外场景音频。
